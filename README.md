# Apple_Freshness_Classifier_GroupEE1

A CNN-based image classifier that predicts whether an apple is Fresh or Rotten, built for GET 324 Mini-Project — Group EE1.

# Overview
- Model: Custom CNN with data augmentation (flip, rotation, zoom, contrast)
- Test accuracy: 95.73%
- Deployed as a Streamlit web app

# Try it
https://appleclassificationgroupee1.streamlit.app/

# Project structure
- `app.py` — Streamlit app
- `Apple_classifier.ipynb` — model training notebook
- `my_mobilenet_model.keras` — trained model
- `datasets/` — training data
- `requirements.txt` — dependencies

# How to run locally
\`\`\`
pip install -r requirements.txt
streamlit run app.py
\`\`\`

# Results
- Training accuracy: 98.95%
- Validation accuracy: 96.51%
- Test accuracy: 95.73%
